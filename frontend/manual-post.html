Como Usar

  1. Selecione o grupo cadastrado em Grupos & Canais.
  2. Digite a mensagem que será publicada.
  3. Opcional: adicione link de imagem ou vídeo.
  4. Escolha: enviar agora ou agendar para depois.
  5. Clique em "Enviar Postagem" para confirmar.
Requisitos Telegram:
  • O grupo deve estar cadastrado com ID numérico (ex: -100...).
  • Configure o token do BotFather ou faça login via Userbot em Configurações & API.
