Parâmetros Operacionais de Segurança

Interrupção Geral de Emergência (Kill Switch)

Suspende instantaneamente qualquer disparo ou publicação agendada no sistema.

A Seção 5.3 especifica 24 horas por padrão para preservar as comunidades e evitar excessos.
Quando ativo, o motor executa a seleção e o histórico sem efetuar disparos reais nas APIs externas.

Integração Telegram Bot API

Obtido ao criar um bot no Telegram com o @BotFather. As credenciais são armazenadas de forma segura.

Infraestrutura de Banco de Dados

Provedor Ativo: Local Resiliente (JSON)
Variáveis Supabase: Não configuradas
Como Conectar o Supabase:
  1. Crie um projeto gratuito em supabase.com.
  2. No SQL Editor do Supabase, cole e execute o script database/schema.sql.
  3. Copie sua URL e chave anon/service_role para o arquivo .env.
  4. Ao reiniciar o servidor, o sistema se conectará automaticamente ao Supabase PostgreSQL!
