Infraestrutura de Banco de Dados

Provedor Ativo: Local Resiliente (JSON)
Variáveis Supabase: Não configuradas
Como Conectar o Supabase:
  1. Crie um projeto gratuito em supabase.com.
  2. No SQL Editor do Supabase, cole e execute o script database/schema.sql.
  3. Copie sua URL e chave anon/service_role para o arquivo .env.
  4. Ao reiniciar o servidor, o sistema se conectará automaticamente ao Supabase PostgreSQL!
